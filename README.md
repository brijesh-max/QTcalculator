# Qt Calculator

A simple calculator application developed using **C++ and Qt Widgets**.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear button
- Backspace button
- Division-by-zero error handling

## Project Files

- `main.cpp` - Application entry point
- `mainwindow.h` - Main window class declaration
- `mainwindow.cpp` - Calculator logic
- `mainwindow.ui` - Graphical user interface designed for Qt Widgets
- `QtCalculator.pro` - Qt project configuration

## How to Run

1. Open `QtCalculator.pro` in Qt Creator.
2. Select a Qt Desktop kit.
3. Build the project.
4. Run the application.
